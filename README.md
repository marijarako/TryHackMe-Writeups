# Cybersecurity Learning Journey & TryHackMe Write-ups

Welcome! This repository serves as a documented log of my continuous progress in mastering practical cybersecurity skills. 

While my initial background is rooted in web application security and source code review, I am using this space to expand my hands-on technical knowledge through platforms like TryHackMe. Here, you will find my write-ups, lab notes, and practical exercises categorized by modules.

## Purpose of this Repository
* **Tracking Progress:** Documenting learning milestones and newly acquired technical skills on a regular basis.
* **Concept Reinforcement:** Writing detailed explanations of vulnerabilities, network protocols, and security tools to solidify my understanding.
* **Practical Portfolio:** Demonstrating my transition from academic, theoretical knowledge to applied, hands-on defensive and offensive security practices.

## Repository Structure
Folders are organized by specific pathways and modules (e.g., `CyberSecurity-101`). Each module folder contains its own `README.md` file featuring:
* Core concepts and methodologies covered.
* Security tools utilized in the labs (e.g., Nmap, Wireshark, Linux CLI).
* Step-by-step methodologies and practical takeaways.
